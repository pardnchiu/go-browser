## Features

> `go get github.com/pardnchiu/go-browser/core` · [Documentation](./doc/doc.md)

- **Chrome Content Extraction** — Renders pages with local Chrome or Chromium and returns Markdown, merged HTML, or a JSON node tree, passing JSON and XML responses through untouched.
- **Multi-Snapshot Merge** — Scrolls and captures a snapshot per step, then merges and deduplicates them to recover lazy-loaded and infinite-scroll content.
- **Chrome Cookie Sessions** — Decrypts cookies from the local Chrome profile and injects them into a temporary browser to read login-required pages.
- **Attempt Cookie Consent Dismissal** — Runs up to two passes to close consent banners and reports the outcome in `Consent`, without promising success on every site.
- **Headless-First Isolation** — Isolates browser instances by headless mode and User-Agent, retrying headed only on 403, 429, or 503 blocks when a display exists.
